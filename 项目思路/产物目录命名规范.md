# 产物目录命名规范（通用约定）

> 适用范围：王者视频解析项目所有子项目及后续阶段
> 制定日期：2026-08-15（源自子项目3 的实践沉淀）
> 目的：确保每一步的**最终结果可追踪、可复盘**——按路径即可还原"哪个阶段、
> 用什么输入、产出了什么"。

## 1. 核心规则

**产物目录 = 产物根目录 + 阶段名**

```
<APPLY_ROOT>\<STAGE_NAME>\
```

- `APPLY_ROOT`：产物根目录，对应一次应用/一份文档场景，如 `D:\wangzhe_project\apply\document1`；
- `STAGE_NAME`：阶段名，与子项目一一对应，统一小写编号命名：`subproject1`、`subproject2`、`subproject3`……

当前实例：`D:\wangzhe_project\apply\document1\subproject3`

## 2. 两类目录的职责分离

| 目录 | 存放内容 | 举例（子项目3） |
| --- | --- | --- |
| **核心目录**（`王者视频解析\<子项目名>\`） | 脚本、映射表/配置、SOP、README 等项目核心内容，保持纯净，**不混入运行产物** | `fill_base_table.py`、`小地图位置.md`、`SOP.md`、`README.md` |
| **产物目录**（`<APPLY_ROOT>\<STAGE_NAME>\`） | 脚本运行产生的一切结果：结果表格、明细 CSV、归档图片等 | `基础表格_填充结果.xlsx`、`UN/`、`EM/` |

## 3. 实现要求（所有子项目脚本统一遵守）

1. **路径配置拆两项**：脚本头部以 `APPLY_ROOT` 和 `STAGE_NAME` 两个常量定义产物目录，
   不写死完整产物路径，便于复制脚本到新阶段时只改 `STAGE_NAME`。
2. **阶段文件夹自动创建**：脚本运行起始处执行
   `OUTPUT_DIR.mkdir(parents=True, exist_ok=True)`，目标文件夹中的阶段文件夹
   **无需手动建立**。
3. **产物可重建**：重复运行应覆盖/重建产物（如 UN/EM 文件夹先清空再生成），
   保证产物始终与当前输入和代码一致；产物目录内不放手工内容。
4. **原件不动**：模板类输入（如基础表格.xlsx）只读，结果一律另存到产物目录。

## 4. 文档同步要求

- 每个子项目的 `SOP.md` 和 `README.md` 必须写明本约定及该阶段的实际产物路径；
- 涉及产物路径的决策变更，同步记录到对应的问答记录文档
  （如 `预期外事件\项目3\项目3 copy.md`）。

## 5. 新阶段接入步骤

1. 复制上一阶段脚本，修改 `STAGE_NAME`（如 `subproject4`）及输入路径；
2. 直接运行——阶段文件夹自动创建，产物自动归位；
3. 在该阶段的 SOP/README 中登记产物路径。
