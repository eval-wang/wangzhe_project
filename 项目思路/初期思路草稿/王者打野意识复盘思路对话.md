### 1. 为什么“地点即行为”能解决“模糊感”？
你说的“模糊感”源于**时间刻度（90s周期）**和**实际地图距离**的脱节。 
你虽然知道90s后蓝buff刷新，但你不知道这90s内你能横跨地图几次。

**“地点即行为”的本质是给时间赋权：**

- 在王者峡谷中，从自家蓝区走到自家红区，约需要 **12-15秒**（视位移技能而定）。
- 你前面算的“刷完蓝等80秒”，这80秒实际上等于：**刷一组小野（7s）+ 赶路到红（15s）+ 再刷一组小野（7s）+ 再赶路……**

所以，你的行为表不应该按“时间刻”来排，而应该按**“路径闭环”**来排。
引入你的符号系统后，一个完美的**90s红蓝闭环**应该是：
`b(蓝) → w(狼) → lz(蜥蜴) → 路过中草 → r(红) → bp(豹子) → z(猪)`
如果你发现你在某个90s周期内，路线变成了 `b → 上路抓人 → 回城 → r`，说明这个周期你**丢失了2组小野的经济**。**复盘时只要看路线图是否“首尾闭环”，立马就能判断经济是否流失，根本不用算数。**

### 2. 补全你的“分阶段决策模型”（解决取舍问题）
你提到4分钟前刷野最优，10分钟后开龙优先。这里有一个**边际效应**需要补丁，否则你复盘时会觉得数据打架：

- **4-10分钟（推塔>刷野>开龙）**：这是对的，但前提是**“推塔能成功”**。
- 你的符号系统里没有加入**“防御塔镀层剩余时间”**。如果4分钟刚到，兵线进塔，你过去推塔，收益是 **（塔的血量+镀层金币）**。但如果对面清线快，你推不掉，你浪费了15秒，这15秒等于损失了2组小野。
- **建议**：在复盘时，给行为加上**“成功率系数”**。比如开龙，如果对面打野阵亡（掉点），开龙成功率90%；如果对面全活着，开龙成功率40%。**你复盘时要比较的是：行为收益 × 成功率**。高风险开龙不如稳稳刷掉自家红区。

### 3. 如何让你的“符号系统”秒杀Excel混乱？
你提到表格杂乱，因为混入了“妲己（击杀）”这种偶然事件。我们可以升级一下你的编码，让它**剔除偶然，直指本质**：

- 把行为分为 **“固定收益”**（野怪、兵线）和 **“概率收益”**（击杀、推塔）。
- **你的符号规则可以这样微调**：
  - **行为符**：`b(蓝)`, `r(红)`, `w(狼)` 表示**刷掉**。
  - **位置符 + 方向**：`b+` 表示入侵对方蓝区，`b-` 表示守自家蓝区。
  - **特殊符**：击杀不记名字（妲己），记为 **`P` (Pick/掉点)**。你只需要记 `P` 发生在哪里（比如 `P在中右草`）。
  
这样一来，你Excel表里的每一行90秒周期就变成了极简公式：
`周期1（0:40-2:10）： b- → w → lz → r- → bp → z` （完美闭环，经济满分）
`周期3（4:00-5:30）： b- → P(中右) → 推中塔 → r-（漏刷bp）`（虽然推塔成功，但漏掉一组小野，属于“用野区经济换节奏”，这个交换是否值？看推塔是否带来后续视野压制）

#### 步骤 2：特征工程（核心！将你的“地点即行为”灌入模型）

| 特征组 | 具体特征名（数值型） | 构造逻辑 |
| :--- | :--- | :--- |
| **地点独热** | `is_b`, `is_r`, `is_l` (龙) ... | 当前时刻所在地点的One-Hot编码 |

#### 步骤 3：构建状态空间（S）与行动空间（A）

这是为了强化学习做准备，但也适用于监督学习。

- **状态 S（t时刻）**：`{ 当前位置符号, 当前时间相位, 全图资源剩余列表（0/1）, 自身经济/等级, 敌方视野分布 }`
- **行动 A（决策输出）**：模型只需要输出 **“下一个目标地点符号”**（例如从18个固定地点中选择1个：`b, r, l, w, z, bp, lz, t1塔, m1塔, b1塔, 水晶...`）。
- **奖励 R（关键！）**：**R = 当前行动后，在接下来30秒内获得的实际经济增量 + 塔推掉的额外系数（+500） - 死亡惩罚（-300）**。这里的系数完全参照你的“阶段权重”（10分钟后推塔系数拉满）。

#### 步骤 4：分层训练策略（两条腿走路）

为了避免强化学习冷启动太难，我们采用**“监督预训练 + 强化精调”**的范式：

1.  **基线模型（行为克隆）**：拿1000场**荣耀王者段位**打野的路径数据，输入LSTM。让模型学会预测“当前状态下，高段位玩家会走向哪个符号”。这相当于给模型一个“好学生”的初始策略。
2.  **优化模型（DQN强化学习）**：在LSTM的基础上，接入DQN的Q-network。让智能体在模拟环境中（或离线数据集上）不断尝试不同的路径选择，**以“步骤3中的奖励R”为唯一标准**，去修正高段位玩家的错误习惯（比如高段位可能为了抢节奏送人头，模型会通过奖励函数惩罚死亡，从而输出更稳的最优解）。

#### 步骤 5：段位适配（如何拟合不同段位的“最佳方案”）

你提到“不同段位”，这里不需要复杂算法，用**“约束屏蔽（Masking）”**即可：

- 在模型输出行动概率之前，根据段位动态屏蔽某些选项。
- **青铜/白银局**：屏蔽“入侵对方野区（大写B/R）”选项，因为低段位队友支援慢，入侵风险极高。模型强制选择自家闭环路径。
- **钻石/星耀局**：开放“入侵”，但将“推塔”行动的奖励系数*1.5，强行引导模型去拆塔。
- **荣耀局**：所有行动开放，且将“开龙（l）”的奖励系数*2.0（因为高段位龙的价值极高）。
*（训练时，只需训练一个基础大模型，推理时改变Reward权重即可，无需重新训练）*

在你的 `mvp.py` 末尾（或新建一个 `data_labeler.py`），添加以下函数。它的逻辑是：**计算当前坐标到所有野怪坐标的欧氏距离，若距离小于阈值（例如0.06），则判定为该野怪；否则标记为“移动中”或“兵线”**。

```python

def label_position(x_norm, y_norm, threshold=0.06):
    """
    输入归一化坐标，输出对应的行为符号

    return best_label
```

1. **矩形框（Bounding Box）**：适合做碰撞检测，但边界模糊（比如蓝buff和狼之间有空地）。
2. **质心点 + 捕获半径（Centroid + Radius）**：以野怪刷新点为中心画一个圆，只要英雄坐标落入圆内，就判定为该野怪。

**我强烈推荐第二种（质心+半径）**，因为它更符合你的“地点即行为”理念——你不需要精确框出野区轮廓，只要知道英雄在某个野怪点附近（比如0.06的归一化距离内），就认为他在刷这组野。这个逻辑简单、抗干扰强，并且完美契合你的ML特征工程。

### 🧭 第二步：编写“坐标→标签”翻译器

这个函数会计算坐标到所有资源点的欧氏距离，选出最近的那个。如果最近距离大于**阈值（推荐0.065）**，就判定为“移动中（moving）”。

```python
def label_position(x_norm, y_norm, threshold=0.065):
    """
    输入归一化坐标，输出对应的行为符号
    """
    min_dist = float('inf')
    best_label = 'moving'  # 默认在赶路

    for label, (cx, cy) in RESOURCE_COORDS.items():
        dist = math.sqrt((x_norm - cx)**2 + (y_norm - cy)**2)
        if dist < min_dist:
            min_dist = dist
            best_label = label

    # 如果距离太远，说明不在任何资源点附近
    if min_dist > threshold:
        return 'moving'
    return best_label
```

## 🧠 第三步：特征工程（把符号转成模型输入）

### 构造训练样本

假设我们有一局的数据，按时间排序。我们取滑动窗口，例如用过去3个时刻的行为和位置预测下一个时刻的行为。

```python
import pandas as pd

df = pd.read_csv('hero_positions.csv')
# 补全缺失值（如果某些时刻未检测到，用前向填充）
df = df.fillna(method='ffill')

# 添加时间相位
def get_phase(t):
    if t < 240: return 0   # 0-4min
    elif t < 600: return 1 # 4-10min
    elif t < 1200: return 2 # 10-20min
    else: return 3
df['phase'] = df['time_sec'].apply(get_phase)

# 生成序列样本：用前3个点预测下一个点的行为
window = 3
X, y = [], []
for i in range(window, len(df)):
    # 特征：过去3个时刻的 (x, y, phase, action_label编码)
    prev = df.iloc[i-window:i]
    # 这里action_label需要数值编码，比如将b, r, L等映射为整数
    # 简单的映射字典
    label_map = {'b':0, 'w':1, 'z':2, ...}
    feats = []
    for _, row in prev.iterrows():
        feats.extend([row['x_norm'], row['y_norm'], row['phase']])
        # 将行为标签也作为特征（上一时刻的行为对下一时刻有影响）
        feats.append(label_map.get(row['action_label'], -1))
    X.append(feats)
    y.append(label_map.get(df.iloc[i]['action_label'], -1))
```

这样我们就有了监督学习的训练集 `(X, y)`，可以训练一个分类器（如XGBoost或LSTM）来预测下一个行为。

## 🎯 第五步：引入奖励机制（强化学习方向）

最终目标是**最大化经济收益**，而不仅仅是行为匹配。我们可以用DQN，但需要定义奖励：

- 开龙 → +团队经济

由于你没有直接的经济数据，可以先用**固定经验值**模拟，等以后解析到经济值再替换。

## 📝 第七步：输出策略表

最终，我们不是输出黑盒模型，而是输出**决策规则**。例如用SHAP分析XGBoost，得到：

```python
def load_grid_map(file_path="scv简化.md"):
    with open(file_path, 'r', encoding='utf-8') as f:

        for row in reader:
            if len(row) < 3:
```

### 🧠 第三步（高阶）：解析网格符号，提取“区域”和“深度”作为双特征

你现在的符号非常精细，比如 `b0`, `b1`, `b2`, `b3` 都表示“蓝区”，但数字代表了距离水晶的远近（深度）。这对于策略决策至关重要——**靠近水晶的野怪（b3）和靠近河道的野怪（b0）价值完全不同**。

为了让机器学习模型更好理解，我们可以对符号做**拆解**，而不是直接当成一个离散标签（因为 `b3` 和 `R3` 虽然数字一样，但意义不同）。

在生成训练集的特征工程阶段，建议将标签拆解为：

```python
def parse_label(label):
    """
    输入 'b0' 返回 ('b', 0)
    输入 'R3' 返回 ('R', 3)
    输入 'L'  返回 ('L', -1)  # -1 表示无深度
    """
    if len(label) == 1:
        return label, -1
    # 如果最后一个字符是数字
    if label[-1].isdigit():
        return label[:-1], int(label[-1])
    # 处理像 'T1' 这样的塔标记
    return label, -1
```

这样，你喂给模型的特征就不是孤立的 50 个类别，而是 **“区域编码（独热）” + “深度值（数值）”**，极大地节约了特征空间，并让模型能理解“蓝区深处”和“蓝区入口”的递进关系。

```python
import csv

def load_grid_map(csv_path):
    """
```

- 英雄的归一化坐标 `(x_norm, y_norm)` 取值范围是 `[0, 1]`，分别对应网格的列（0~19）和行（0~19）。
- **离散化方法**：用四舍五入（`round`）或向下取整（`int`）。推荐使用 **四舍五入**，这样坐标位于格子中心附近时会被分到最近的格子。  
  - `col = min(round(x_norm * 20), 19)`  
  - `row = min(round(y_norm * 20), 19)`
- 边界处理：当 `x_norm` 或 `y_norm` 恰好为 1.0 时，`round` 可能得到 20，需要钳制到 19。

### 步骤 3：查表获取符号
- 用 `(row, col)` 在 `grid` 数组中查找符号，如果为 `None`，则赋予 `'unknown'`。

### 步骤 4：修改主流程，输出扩展后的 CSV
- 在原有代码中，每 3 秒检测到英雄位置后，除了记录时间和归一化坐标，还要：
  - 计算离散行列
  - 查询符号
  - 将 `time_sec, x_norm, y_norm, row, col, symbol` 写入 CSV
- 同时保留原有的标记图保存功能（可选）。

- 可能存在空行或格式问题，需要跳过空行。

### 🧭 坐标转换的精确理解

- 如果 `detect_hero` 返回 `None`（未检测到英雄），则对应记录 `row=None, col=None, symbol=None`，但为了 CSV 整洁，可以标记为 `'none'`。

请将以下代码保存为 `mvp_with_grid.py`（或直接替换原文件）。

```python
import cv2
import numpy as np
import csv
import os

# ==================== 配置区 ====================
VIDEO_PATH = r"D:\b站视频\素材\2月8日 (短视频测试).mp4"   # 你的视频路径
MINIMAP_ROI = (840, 310, 1440, 1380)                # 小地图裁剪区域
HERO_COLOR = "hero"

# 网格映射表文件路径（请确保路径正确）
GRID_MAP_FILE = r"D:\study_hub\scv简化.md"          # 你的网格符号表

# 颜色范围（针对 RGB(115,170,105) 英雄）
COLOR_RANGES = {
    "hero": [(np.array([55, 80, 90]), np.array([75, 200, 220]))]
}
# =================================================

# ---------- 1. 读取网格映射表 ----------
def load_grid_map(file_path):
    """
    从文本文件加载 20x20 网格映射表
    返回：grid[20][20] 列表，每个元素是符号字符串或 None
    """
    grid = [[None for _ in range(20)] for _ in range(20)]
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            for line in f:
                line = line.strip()
                if not line:
                    continue
                parts = line.split(',')
                if len(parts) != 3:
                    continue
                row = int(parts[0].strip())
                col = int(parts[1].strip())
                symbol = parts[2].strip()
                if 0 <= row < 20 and 0 <= col < 20:
                    grid[row][col] = symbol
    except FileNotFoundError:
        print(f"⚠️ 网格映射文件未找到: {file_path}")
        print("将不使用网格映射，所有符号标记为 'unknown'")
        return None
    return grid

grid = load_grid_map(GRID_MAP_FILE)

# ---------- 2. 坐标转网格符号的函数 ----------
def get_grid_symbol(x_norm, y_norm, grid):
    """
    输入归一化坐标 (0~1)，返回对应的网格行列和符号
    如果 grid 为 None，则返回 (None, None, 'unknown')
    """
    if grid is None:
        return None, None, 'unknown'
    
    # 四舍五入并钳制到 0~19
    col = round(x_norm * 20)
    row = round(y_norm * 20)
    col = min(max(col, 0), 19)
    row = min(max(row, 0), 19)
    
    symbol = grid[row][col]
    if symbol is None:
        symbol = 'unknown'
    return row, col, symbol

# ---------- 3. 英雄检测函数（原样） ----------
def detect_hero(minimap, color_ranges):
    hsv = cv2.cvtColor(minimap, cv2.COLOR_BGR2HSV)
    mask = np.zeros(hsv.shape[:2], dtype=np.uint8)
    for lower, upper in color_ranges:
        mask |= cv2.inRange(hsv, lower, upper)
    
    kernel = np.ones((3,3), np.uint8)
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)
    
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    if contours:
        largest = max(contours, key=cv2.contourArea)
        if cv2.contourArea(largest) > 10:
            M = cv2.moments(largest)
            cx = int(M["m10"] / M["m00"])
            cy = int(M["m01"] / M["m00"])
            return (cx, cy)
    return None

# ---------- 4. 主流程 ----------
cap = cv2.VideoCapture(VIDEO_PATH)
if not cap.isOpened():
    print("❌ 视频打开失败！请检查路径（建议纯英文路径）")
    exit()

# 获取视频尺寸
frame_width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
frame_height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
print(f"📐 视频分辨率: {frame_width} x {frame_height}")

# 自适应修正 ROI
x, y, w, h = MINIMAP_ROI
if x + w > frame_width:
    w = frame_width - x
if y + h > frame_height:
    h = frame_height - y
if w <= 0 or h <= 0:
    print("❌ ROI 越界，请重新标定")
    exit()
MINIMAP_ROI = (x, y, w, h)
print(f"✅ 最终 ROI: {MINIMAP_ROI}")

fps = cap.get(cv2.CAP_PROP_FPS)
frame_interval = int(fps * 3)  # 每 3 秒采样一次

results = []
frame_count = 0

while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    if frame_count % frame_interval == 0:
        t_sec = round(frame_count / fps, 1)
        minimap = frame[y:y+h, x:x+w]
        pos = detect_hero(minimap, COLOR_RANGES[HERO_COLOR])
        
        if pos:
            # 归一化坐标
            x_norm = round(pos[0] / w, 3)
            y_norm = round(pos[1] / h, 3)
            
            # 映射到网格符号
            row, col, symbol = get_grid_symbol(x_norm, y_norm, grid)
            
            # 记录数据
            results.append([t_sec, x_norm, y_norm, row, col, symbol])
            print(f"⏱️ {t_sec}s → ({x_norm}, {y_norm}) → 网格({row},{col}) → {symbol}")
            
            # （可选）保存标记图
            marked_minimap = minimap.copy()
            cv2.circle(marked_minimap, pos, radius=5, color=(0,0,255), thickness=-1)
            output_img_path = f"marked_frame_{int(t_sec)}s.jpg"
            cv2.imwrite(output_img_path, marked_minimap)
            print(f"    📸 已保存标记图: {output_img_path}")
        else:
            # 未检测到英雄
            results.append([t_sec, None, None, None, None, 'none'])
            print(f"⏱️ {t_sec}s → 未检测到英雄")
    
    frame_count += 1

cap.release()

# ---------- 5. 保存 CSV ----------
output_path = "hero_positions_labeled.csv"
with open(output_path, 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['time_sec', 'x_norm', 'y_norm', 'grid_row', 'grid_col', 'symbol'])
    writer.writerows(results)

print(f"\n✅ 处理完成！结果已保存至: {os.path.abspath(output_path)}")
print("💡 用 Excel 打开，即可看到每个时刻的网格符号")
```
