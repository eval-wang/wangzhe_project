## [1.2.0] - 2026-08-22

### 配套工具（位置标注 HTML）

#### 新增

- `配套工具/位置示意图_防御塔配置.html`：完整版 + 防御塔一键配置
  - 网格下方新增**两个宽扁配置窗口**：左侧"⚪ 我方"、右侧"⚫ 敌方"，
    各有 上/中/下 三个数字框（0–3，表示该路**剩余**防御塔数量，非法输入自动夹取）
  - **🏰 一键生成防御塔**：清空棋盘后按游戏规则自动落子——外塔先毁、内塔留存
    （剩 3 = 一/二/三塔全在；剩 2 = 二塔+三塔；剩 1 = 仅三塔；剩 0 = 该路全毁）
  - 我方防御塔 = 白色棋子，敌方 = 黑色棋子，每塔按 2×2 区块落 4 子
  - 可选"同时放置双方水晶"（默认勾选）；生成结果自动同步 CSV 至导出框，
    便于复制存档或继续手动微调
- `配套工具/位置示意图-纯净版-防御塔配置.html`：极简分屏版 + 防御塔一键配置
  - 在纯净版基础上仅增加底部**一条窄控制条**（六个数字框 + 生成按钮 + 水晶勾选框）
  - 棋盘始终占满控制条以外区域并保持最大正方形，窗口拉窄（分屏）时实时自适应
  - 生成规则与完整版一致，保留左/右键手动落子微调

  - 项目背景：离散数学形式化训练 → MOBA"定式"建模的完整思路

#### 新增

- `配套工具/位置示意图.html`：基于 20×20 网格地图的可视化位置标注工具
  - 固定背景图自动加载（`相关素材/地图/正方形.png`），支持手动更换
  - **围棋式落子交互**：左键放置/移除白色棋子，右键放置/移除黑色棋子，
    再次点击同色棋子即移除（对应"英雄=网格上的动态落子点"的建模思路）
  - 棋盘（表格）置顶显示，全黑背景，棋子以圆形绘制（含高光/阴影）便于辨识
  - CSV 导出 / 反向导入 / 复制，符号约定 `W`=白棋、`B`=黑棋，可对接阶段3 表格
- `配套工具/位置示意图-纯净版.html`：纯净版页面，仅保留地图本体
  - 去掉全部文字信息与控件，只显示地图
  - 页面与地图始终为正方形（`100vmin`），随视口实时自适应，可无缝嵌入复盘/演示

#### 变更

- 原 `配套工具/网格导出图.html` 更名为 `位置示意图.html`，输入逻辑由文本标注
  改为围棋式黑白棋子落子，移除弹窗输入（prompt）

## [1.0.0] - 2026-08-17

### Pipeline（视频解析流水线）

首个可全链路运行的版本。

#### 新增

- `pipeline.py` 一键调度入口（`--document` 指定对局）
- `stage1_extract.py`：阶段1 规范化副本——40s 起抽帧、3s 间隔、至视频结束，
  产物自动归入 `subproject1\`（子项目1 原脚本零改动）
- `stage2_detect.py`：英雄检测 + EM 归档
  - 多进程并行（默认 6 worker，0.3 → 1.9 帧/秒）
  - 断点续跑（逐条落盘，重跑自动跳过已检测帧）
- `stage3_locate_fill.py`：floor 网格映射 + 符号查表 + 时间格填表 + UN 归档
- 专用虚拟环境 `.venv`：opencv 4.10.0.84 / sklearn 1.6.1 / numpy 2.0.2
  （与模型训练版本对齐，规避 OpenCV 5.0 与 sklearn 1.9 兼容问题）
- 工程文档：ARCHITECTURE / TECHNICAL_DESIGN / DATA_CONTRACTS / DEVELOPMENT /
  ROADMAP / CONTRIBUTING / CHANGELOG

#### 验证

- document2（13:45 / 60.4fps / 1280×582）全链路实跑：
  阶段1 263 帧（正常 251 / 异常 12）；阶段2 found 217 / EM 34；
  阶段3 填充 53 格 / UN 75。总耗时约 5 分钟。
- 检测链路冒烟测试：test1 已知帧输出 `(95, 143)`，与历史结果一致。
