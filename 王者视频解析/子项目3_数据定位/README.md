## 核心规则

- 符号来源：仅用采样数据的 (row, col) 查 `小地图位置.md`，CSV 自带的符号列不使用；
- 时间网格：从 0:40 起，15 秒一格，6 行 × 90 秒一列，左闭右开，边界点归入后一格；
- 单元格值：符号 / `EM`（empty 帧）/ `UN`（未标注点），同格多事件按时间顺序用 `_` 拼接；
- time_s < 40 的采样点丢弃；15:40 之后无数据留空；
- 基础表格原件永不修改，结果一律另存。
