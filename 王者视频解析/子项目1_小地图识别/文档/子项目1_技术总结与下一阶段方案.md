## 一、项目目标

从**任意分辨率/设备的王者荣耀完整游戏画面**中，自动精确裁切出小地图正方形区域，输出用于后续网格覆盖分析。

---

## 二、已完成的探索与经验教训

### 2.1 四个阶段的尝试

| 阶段 | 方案 | 结果 | 失败原因 |
|------|------|------|----------|
| 1 | HoughCircles 圆点检测 | IoU 虚高 0.82，实际完全跑偏 | 标注对象错误（标注了黑边而非小地图本体） |
| 2 | 几何规则硬编码 | 对 test1 无效 | 不同设备小地图位置不同，不能写死 |
| 3 | 模板匹配标注 + GBR | IoU=0.87，实际偏差 20~30px | 22 条低分样本污染训练集 |
| 4 | 数据清洗 + RandomForest | IoU=0.972，偏差约 ±10px | 训练数据仅 2 种分辨率，泛化能力不足 |

### 2.2 核心教训

1. **数据质量 > 模型复杂度**：清理 22 条异常样本后 IoU 从 0.87→0.97
2. **单一数据源无法泛化**：130 条标注全来自 2 种分辨率，模型学的是"查表"而非"定位"
3. **标注边界必须明确定义**：装饰框/地图纹理的取舍直接影响模型精度
4. **特殊情况必须显式处理**：死亡遮挡、敌方视角、过场动画等不能忽略

### 2.3 当前可复用的技术资产

| 资产 | 路径 | 说明 |
|------|------|------|
| 训练脚本 | `core/train_model.py` | RandomForest + 233 维特征，支持交叉验证 |
| 预测脚本 | `core/predict.py` | 加载模型、批量预测、输出裁剪+可视化 |
| 标注脚本 | `core/process_materials.py` | 从配对数据（完整画面+小地图切片）自动标注 |
| 标注工具 | `标注工具.py` | Python GUI，鼠标拖拽标注 + 方向键微调 |
| 复盘文档 | `子项目1_复盘与技术确认.md` | 五大问题的详细分析 |

## 三、用户确认的技术方案

### 3.1 输入输出定义

| 项目 | 定义 |
|------|------|
| 输入 | 任意分辨率的完整游戏画面（JPG） |
| 输出 | 小地图矩形框 `[left, top, right, bottom]`（像素坐标） |
| 正方形要求 | 是（裁切时取短边，以左上角为锚点） |
| 精度要求 | 每条边偏差 ≤ 1px |

### 3.2 裁切边界定义（B 层）

```
┌─────────────────────────┐
│  [状态栏: 0:03]         │  ← A 层（不取）
│  ┌───────────────────┐  │
│  │ ╔═══════════════╗ │  │  ← B 层：紫色/金色边框内侧（我们的目标）
│  │ ║ 地图内容      ║ │  │
│  │ ║ (地形+英雄)   ║ │  │  ← C 层（太紧，会丢边角信息）
│  │ ╚═══════════════╝ │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

参照 `相关素材/地图/正方形.png` 的覆盖范围。

### 3.3 特殊情况处理策略

| 场景 | 处理方式 |
|------|----------|
| 小地图正常可见 | 输出精确 ROI |
| 小地图被遮挡（死亡/UI弹窗） | 输出空 |
| 敌方视角（镜像翻转） | 特殊标记 |
| 过场动画（无小地图） | 跳过 |
| 完全不同版本 UI | 单独建仓库判断 |

### 3.4 量化测试标准

| 指标 | 要求 |
|------|------|
| 每条边最大偏差 | 1 px |
| 合格率要求 | ≥ 95% |
| 不合格帧处理 | 标记为输出空或跳过 |

## 四、下一阶段数据需求

### 4.1 数据集结构

```
D:\wangzhe_project\screeshot_collection\train_collection\
├── device_01\          # 设备类型 1（如 1280×720 横屏）
│   ├── full\           # 完整游戏画面
│   │   ├── frame_0000.jpg
│   │   ├── frame_0001.jpg
│   │   └── ...
│   ├── minimap\        # （可选）对应的小地图高清切片
│   │   ├── frame_0000.jpg
│   │   └── ...
│   └── labels.json     # 标注文件
│
├── device_02\          # 设备类型 2（如 1920×1080 横屏）
│   ├── full\
│   ├── minimap\        # 可选
│   └── labels.json
│
├── device_03\          # 设备类型 3（如 1080×1920 竖屏）
│   ├── full\
│   └── labels.json
│
├── special\            # 特殊情况
│   ├── death\          # 死亡遮挡
│   ├── enemy_view\     # 敌方视角
│   └── labels.json     # 空标注或特殊标记
│
└── ...
```

### 4.2 每种设备类型的建议数据量

| 设备类型 | 建议样本数 | 说明 |
|----------|-----------|------|
| 每种分辨率 | 30~50 张 | 覆盖不同游戏时间点（开局/中期/后期），不同英雄位置 |
| 特殊情况 | 10~20 张/类 | 死亡遮挡、敌方视角、过场动画 |
| 总目标 | 150~250 张 | 覆盖 ≥ 3 种不同分辨率 |

### 4.3 labels.json 格式

```json
[
  {
    "file": "frame_0000.jpg",
    "image_size": [1280, 720],
    "roi": [0, 26, 206, 232],
    "flags": ""
  },
  {
    "file": "frame_0050.jpg",
    "image_size": [1280, 720],
    "roi": [0, 0, 0, 0],
    "flags": "death"
  },
  {
    "file": "frame_0100.jpg",
    "image_size": [1280, 720],
    "roi": [0, 26, 206, 232],
    "flags": "enemy_view"
  }
]
```

- `roi: [0,0,0,0]` 表示该帧无小地图（被遮挡/过场动画）
- `flags: ""` 正常帧
- `flags: "death"` 死亡遮挡
- `flags: "enemy_view"` 敌方视角
- `flags: "skip"` 跳过该帧

## 五、数据标注工具

### 5.1 工具位置

```
D:\wangzhe_project\王者视频解析\子项目1_小地图识别\标注工具.py
```

### 5.2 使用方法

```bash
# 启动标注工具
python 标注工具.py
```

### 5.3 操作说明

| 操作 | 快捷键/方法 |
|------|------------|
| 打开图片目录 | 点击"打开目录"按钮 |
| 画框 | 鼠标在图片上拖拽 |
| 微调位置 | 方向键（1px），Shift+方向键（5px） |
| 缩放框大小 | + / - 键 |
| 确认并下一张 | Enter |
| 清除标注 | Backspace 或 R |
| 上一张/下一张 | ← → 键 |
| 保存标注 | Ctrl+S（保存到 labels.json） |
| 导出裁切图 | Ctrl+E |

### 5.4 标注流程建议

1. 打开标注工具
2. 点击"打开目录"，选择 `device_01/full/`
3. 对每张图，在左上角小地图区域拖拽画框
4. 用方向键微调到精确贴合边框内侧（B 层）
5. Enter 确认并跳下一张
6. 遇到死亡遮挡/无小地图的帧，直接 Enter 跳过（不画框）
7. 全部标注完成后 Ctrl+S 保存
8. 将生成的 `labels.json` 放在 `device_01/` 目录下
