# 子项目2 英雄头像识别 - 验证报告

> **日期**：2026-08-06
> **数据**：`D:\wangzhe_project\selected_screenshot_collection\train1`（71 张 ~186×186 小地图，60 条绿框标注）
> **代码**：`hero_detect.py` v2（双掩膜环形模板 + 融合打分）

---

## 一、最终方案

```
186×186 小地图
  │
  ├─ 1. 双通道 HSV 颜色过滤
  │      green: H[45,95]  S>50 V>55   （绿环本色）
  │      cyan : H[95,112] S>40 V>55   （泉水治疗光把绿环染青，覆盖率门槛更高）
  │      + 3×3 闭运算连接 1-3px 断续细线
  │
  ├─ 2. 环形模板匹配（半径 10-14 多尺度卷积）
  │      响应 = 环上同色像素覆盖率，可容忍部分遮挡
  │      抑制项：环有效占比 ≥0.6（防边缘虚高）、环内部同色占比 ≤0.3（防草丛/河道实心块）
  │
  ├─ 3. 贪婪 NMS（半径 6px）→ 候选圆心列表
  │
  └─ 4. 身份确认融合打分
         fused = NCC(候选, 参考模板top5均值) + RF分类器概率 + 0.3×覆盖率
         fused ≥ 1.05 才输出 argmax 候选，否则输出 None
```

参考模板与 RF 模型均由 `train_hero_model.py` 生成，存于 `release/hero_model.pkl`：
- 正样本 60 条标注框 patch + 数据增强（旋转/亮度/翻转/平移）→ 600 条
- 负样本：随机采样 240 条 + **难负样本挖掘** 710 条（检测候选中"像绿环但不是目标"的干扰：主宰坑、基地 UI、复活特效等）

## 二、验证结果

### 2.1 全量验证（模型见过这些帧，偏乐观）

| 指标 | 结果 |
|------|------|
| 有标注图命中率（圆心误差 ≤5px） | **54/60 (90.0%)** |
| 命中帧圆心误差 | 均值 1.72px，中位 1.0px |
| 无标注图正确拒绝（英雄死亡/消失输出 None） | 8/11 |
| 误报 | 3/11 |

### 2.2 诚实评估（帧级对半划分：30 帧训练 / 30 帧未见测试）

| 指标 | 结果 |
|------|------|
| 候选生成召回率（真值 5px 内有候选） | 27/30 (90%) |
| **端到端命中率（未见帧）** | **20/30 (67%)** |
| 无标注帧误报 | 0/11 |

### 2.3 打分方式对比（未见帧实验，argmax 无阈值）

| 打分方式 | 命中率 |
|----------|--------|
| 仅 RF 分类器 | 13/30 (43%) |
| 仅模板 NCC | 16/30 (53%) |
| NCC + 分类器 + 覆盖率（融合） | **23/30 (77%)** |

→ 融合打分显著优于任何单一路径，是本次最关键的改进。

## 三、失败模式分析（剩余 6 漏检 + 3 误报）

| 类型 | 案例 | 原因 |
|------|------|------|
| 泉水染色 | frame_0038/0067 | 治疗光把绿环染青， cyan 通道有候选但融合分低于阈值，保守拒答 |
| 完全遮挡 | frame_0068 | 绿环覆盖率≈0，README 已列为不支持场景 |
| 候选缺失 | frame_0006 | 环被遮挡过重，候选生成阶段未覆盖（召回上限 90%） |
| 重叠误选 | frame_0025/0069 | 两个英雄头像紧贴，相邻头像得分略高，偏差 6-8px |
| 复活特效 | frame_0024 | 死亡后中央绿色漩涡特效形似绿环（已入难负样本仍有个案漏网） |

## 四、结论与建议

1. **管线已可用**：`python hero_detect.py <图片>` 单张检测，`--validate` 全量验证，
   调试图输出到 `debug_output/`（蓝=标注真值，黄=候选，红=最终输出）。
2. **未达 README 的 >95% 验收线**：瓶颈不是算法调参，而是训练数据单一
   （60 条标注全部来自同一局录像，场景/光照/遮挡模式重复）。
3. **下一步建议**（按性价比排序）：
   - 从 2-3 局不同录像各抽 20-30 帧标注（尤其团战、泉水、死亡场景），
     加入训练后重跑 `train_hero_model.py` + `hero_detect.py --validate` 即可
   - 若仍不足，按 README 中期路线升级轻量 CNN
   - 重叠误选可引入 README 长期路线的时序追踪修正
4. 注意：换英雄（非露娜）需重新标注训练；换分辨率需重调环半径范围。
