## 一、原始思路（用户原话整理）

- 新建文件夹 `半自动复盘`，在其中实现一个**手工标注工具**。
- 通过**鼠标点击位置**进行数据标注，对**单个英雄**进行**每 3 秒一次**的采样。
- 操作流程：鼠标点击一个格子后，自动跳到"下一张小地图"，并记录点击的位置；每张"小地图"上显示具体时间。
- HTML 样式参考：`D:\wangzhe_project\团战定式复盘\位置示意图-纯净版-防御塔配置.html`
- 工作流程参考：`D:\wangzhe_project\pipeline\README.md`，但**不使用自动化识别方案**，改用手工标注数据点。

### 与自动 pipeline 的对应关系

本工具**取代阶段1（抽帧裁切）和阶段2（英雄检测）**：用户自己看视频、直接看大地图位置，手工点击产生 (时间, 行, 列) 数据，替代 `hero_position.csv` 的自动生成。阶段3（符号映射 + 填表）的思路保留、后续衔接。

## 五、实现方案（已定稿，2026-08-29）

工具文件：`标注工具.html`（单文件页面，同目录依赖 `xlsx.full.min.js`）。

- **页面**：顶部大号时钟（mm:ss，00:30 起）+ 采样点序号 + 悬停坐标；中部 20×20 网格棋盘（A–T / 1–20 标注、`正方形.png` 底图）；底部按钮与最近记录条。
- **标注**：点击格子 → 记录 `{row, col, 符号}`（符号查 `小地图位置.md`，查不到记 UN）→ 时间 +3s → 棋盘清空进入下一采样点。
- **跳过**：Enter / "跳过 EM" 按钮 → 该点记 `EM` 并前进。
- **导航**：← / → 在采样点间移动；回看时点格子**覆盖**该点记录。
- **撤回**：Backspace / "撤回" 按钮 → 在末尾则删除最后一条；在回看中则删除当前点（后续采样点随下标前移，时间自动对齐）。
- **另存为**：内嵌符号表与填表逻辑，直接产出 `基础表格_填充结果.xlsx`（基准 00:30，15s×6 行×17 列，`_` 拼接不去重，EM/UN 规则同阶段3）；优先调系统"另存为"对话框，失败回退普通下载。
- **符号表注入**：`symbol_map.json` 由 `小地图位置.md` 导出，构建时注入 HTML 的 `SYMBOL_MAP` 常量（file:// 下 fetch 会被浏览器拦截，故不用运行时加载）。符号表更新后需重新注入。
