# 半自动复盘 · 手工标注工具

> 用"看视频 + 鼠标点格子"替代 pipeline 的阶段1（抽帧）与阶段2（英雄检测），
> 对单个英雄做每 3 秒一次的位置采样，直接产出阶段3同规格的时间格填充表格。

## 这是什么

pipeline 的自动识别链路（抽帧 → 检测 → 网格映射）在"只看小地图、只认露娜绿框"的
限制下不够通用。本工具换一条路线：**人眼看视频里的大地图，手点 20×20 网格地图**，
用人工标注取代阶段1+2，同时内嵌阶段3的符号映射与填表规则，一步导出最终表格。

```
视频（人眼看大地图）
    │
    ▼  手工标注：每 3 秒点一次格子（本工具）
(时间, 行, 列, 符号) 采样序列
    │
    ▼  另存为：内嵌符号映射 + 时间格填表（阶段3同规则）
基础表格_填充结果.xlsx
```

## 快速开始

双击打开 `标注工具.html`（依赖同目录 `xlsx.full.min.js`，不要分开移动）。

1. 打开对局视频，从 **00:30** 开始盯目标英雄；
2. 每 3 秒在棋盘上点一次英雄所在格子 —— 点击后时间 +3 秒、棋盘自动清空；
3. 英雄死亡/看不清时按 **Enter** 跳过（记为 `EM`）；
4. 点错了按 **Backspace** 撤回；用 **← / →** 回看任意采样点，回看时点格子即**覆盖**该点；
5. 标完点 **另存为 xlsx**，得到 `基础表格_填充结果.xlsx`。

## 操作速查

| 操作 | 效果 |
|---|---|
| 左键点击格子 | 记录该点坐标与符号，进入下一采样点（回看时=覆盖当前点） |
| Enter /「跳过 EM」 | 当前采样点记 `EM`（无法标注），进入下一点 |
| ← / → | 在采样点之间移动（回看模式，当前点在记录条中高亮） |
| Backspace /「撤回」 | 末尾：删最后一条；回看中：删当前点（后续点时间随之前移） |
| 「另存为 xlsx」 | 弹系统另存对话框导出填充表格（失败时回退普通下载） |

## 数据规则（与阶段3对齐）

- **采样**：起点 00:30，间隔 3 秒，第 i 点对应时刻 `30 + 3i` 秒；
- **符号**：点击格 (行,列) 查 `小地图位置.md` 映射表，查不到记 `UN`；
- **填表**：基准 00:30，15 秒一格、每列 6 行（90 秒）、共 17 列（至 24:30），
  同格多事件按时间顺序用 `_` 拼接、不去重，超出范围丢弃并提示；
- **表格模板**：`基础表格_基准0030.xlsx`（原 40s 基准模板未改动）。

## 维护说明

- **符号表更新**：`小地图位置.md` 改动后，需重新导出 JSON 并注入 HTML 的
  `SYMBOL_MAP` 常量（file:// 下浏览器禁止 fetch 本地文件，故采用构建时注入）；
- **时间基准调整**：改 HTML 顶部的 `START_S` / `TBL_START_S` 常量即可，
  导出表头由代码生成，无需依赖模板文件；
- **棋盘底图**：自动加载 `相关素材\地图\正方形.png`，加载失败时退化为纯黑网格，
  不影响标注。
